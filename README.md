# 틈날때버는월급

커피 한 잔, 스트레칭 한 번. 쉬는 틈을 기록하면 내 연봉 기준으로 얼마어치였는지 보여주고, 미션과 보너스 광고로 진짜 포인트도 쌓는 직장인 쉼 기록 서비스의 프로토타입.

- `index.html` — 메인 (A안). 첫 방문 안내 → 연봉 설정 → 틈 타이머(종류 4가지, 새로고침해도 이어짐) · 등급 · 이번 주 기록 · 미션 · 업종별 쉼(예시 수치) · 명세서(이미지 저장/텍스트 복사) · 보너스 광고 · 교환
- `archive/b.html` — 비교용으로 남겨둔 B안 월급루팡

시연용: 기록·계정은 브라우저 localStorage에만 저장. 로그인은 교환할 때만 필요.
