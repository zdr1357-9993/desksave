# 틈날때버는월급

틈새 속 광고 하나 보고 가세요. 커피 기다리는 15초를 돈으로 바꾸는 직장인 리워드 앱(PWA 프로토타입).

- 모바일 우선, 홈 화면에 설치 가능(PWA: manifest + service worker)
- 지금: 시간대에 맞는 순간 추천 → 열자마자 광고 → 즉시 보상 + 가끔 행운 2배 → 목표 바
- 틈 일기: 오늘의 틈 카드, 이번 주 기록
- 틈이 방: 캐릭터 성장(레벨이 오르면 광고당 포인트 +1), 포인트로만 꾸미기, 성과
- 지갑: 목표 선택, 교환(교환할 때만 로그인)
- 알림: 순간별 켜기, 하루 최대, 조용한 시간, 무시하면 스스로 줄이기
- `archive/` 이전 B안

시연용: 기록은 기기 localStorage에만 저장. 광고는 예시.
