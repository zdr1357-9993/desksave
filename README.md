# 틈날때버는월급

커피 한 잔, 스트레칭 한 번. 쉬는 틈을 켜두고 15초 광고 한 편 보며 포인트를 쌓는 직장인 쉼 기록 서비스의 프로토타입.

- `index.html` — 메인 (A안). 첫 방문 안내 → 틈 타이머(종류 4가지, 새로고침해도 이어짐) · 등급 · 이번 주 기록 · 미션 · 오늘의 틈 광고 목록 · 명세서(이미지 저장/텍스트 복사) · 틈 중 광고 바로 보기 · 교환
- `archive/b.html` — 비교용으로 남겨둔 B안 월급루팡

시연용: 기록·계정은 브라우저 localStorage에만 저장. 로그인은 교환할 때만 필요.
