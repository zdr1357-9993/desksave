# 틈날때버는월급 / 월급루팡

쉬는 시간을 내 연봉으로 환산해 보여주고, 원하면 짧은 광고로 진짜 포인트도 받는 직장인 서비스의 컨셉 비교용 페이지.

- `index.html` — A안/B안 선택 화면
- `a.html` — A안 틈날때버는월급 (따뜻한 버전)
- `b.html` — B안 월급루팡 (장난스러운 버전)
- `app.js` — 두 안이 함께 쓰는 엔진 (틈 타이머·연봉 환산·등급·미션·업종 리그·보너스 광고·교환·명세서)

시연용: 기록·계정은 브라우저 localStorage에만 저장. 로그인은 교환할 때만 필요.
